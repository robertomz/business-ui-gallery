About this screen

  • Each reconciliation code pairs a group of documents with the accounts they should reach, so new checks are added by configuration, not code.
  • The result of each day is written as text with an icon, so it does not depend on color alone.
  • Totals follow the filter: with "only days with difference" on, the footer adds up only the days shown.
  • Opening a day lists the documents and entries involved, which usually explains the difference right away.
