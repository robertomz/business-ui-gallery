About this screen

  • The real version is fed by a nightly job that closes each day, so past days load instantly and today is calculated live.
  • Comparisons use the same weekday of the previous week, because a Monday is not comparable with a Saturday.
  • The day summary works like a ladder: total, the parts that make it up, what is subtracted and the result.
