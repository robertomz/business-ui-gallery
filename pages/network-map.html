About this screen

  • The real tool discovers switches and the devices behind each port, then keeps polling them, so the map draws itself instead of being maintained by hand.
  • Shape tells the device type and color tells the status; the status is also written in the label, the side panel and the table.
  • The table under the map is the same data as text, so it works with a screen reader and on a small phone.
