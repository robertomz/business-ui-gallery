About this screen

      
    
        
  • This screen was used to migrate the catalog of a legacy ERP to a new one without losing stock or sales history: nothing moves until every old item points to a new item, or is marked to be created as new.
    • 
        
  • Suggestions combine three signals (same code, name similarity and same presentation) into one score; the user confirms, changes or rejects each one, and progress is measured by items and by stock value.
    • 
        
  • When two old items point to the same new item they are flagged as duplicates, because their stock would be added together.
    • 
        
  • Duplicates found later in the new catalog are merged with a locked process: preview, dry run inside a transaction that is rolled back, a typed confirmation code, and the retired item kept as not available so old documents still open.
