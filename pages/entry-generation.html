About this screen

  • Generation runs one day and one source at a time, so a long range shows progress and can be cancelled without leaving half a day posted.
  • Days that already have an entry for a source are skipped, so running the same range twice never duplicates anything.
  • Each entry keeps one line per account and side, with the amounts added up. The documents behind each line are in a separate detail table.
  • In production each step is one request to a stored procedure, and the browser drives the loop.
